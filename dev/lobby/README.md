# 로비 새 배경 시안 (11-13)

`index.html`은 혼자 열리는 움직이는 시안이다. 게임에는 아직 넣지 않았다.
로컬에서 볼 때는 이 폴더를 웹 서버로 열어야 한다(`file://`로 열면 하늘 그림을 읽지 못한다).
예: `cd dev/lobby && python3 -m http.server` → http://localhost:8000/
주소 뒤에 `?lives=60`을 붙이면 기록이 있는 사람의 화면이 된다(없으면 첫 방문 화면).

## 정한 것
- 밤 한 가지만 쓴다(시간대 · 낮은 쓰지 않는다).
- 네 판을 접속할 때마다 무작위로 보여 준다. 직전 판은 연달아 나오지 않는다.
  | 판 | 하늘 그림 | 지상 |
  |---|---|---|
  | ① 산 너머 들판 | sky1 은하수 | 산줄기 세 겹, 호수 |
  | ② 강을 낀 큰 도시 | sky2 분홍빛 구름 | 굽은 강, 다리 일곱 |
  | ③ 항구 도시 | sky3 달 | 초승달 만, 부두, 등대 |
  | ④ 분지의 도시 | sky4 유성 | 둘러싼 산, 고리 길 |
- 하늘 그림은 사용자가 만든 그림(웹에서 가져온 그림은 쓰지 않는다). 가로 그림 한 장을 세로 화면에서는 잘라 쓴다.
- 도시 불빛 = 살아 본 생의 수, 영령의 별 = 도감에서 만난 영령 수. 0이면 불도 별도 없다.
- 길 · 고리 · 다리 같은 선은 옅게.
- 움직임: 열릴 때 별이 떠오르고 창불이 차례로 켜짐, 별 반짝임, 창불 깜빡임, 별똥별, 길 위 불빛, ③ 등대 · 물그림자, ② 배, ④ 유성 꼬리. 하늘은 움직이지 않는다(흐름 · 마우스 따라 밀림 없음).
- 도시 아랫줄은 늘 버튼 묶음 바로 위에 온다. 배경 폭의 78%는 늘 보인다.
- 로비 구성: 언어 · 소리 · 설정(위), 픽업 알림, 태어나기 + 성별, 이어하기, 인연 소환, 도감 · 지난 생들 · 업적, 패치 노트 · 시나리오 · 의견 보내기 · 앱으로 설치, (가로 화면) 단축키.
- 소개글 · 숫자 · 규칙 · 안내문은 「이 밤의 이야기와 규칙」으로 펼쳐 본다. 배경 위에 옅은 검은 막을 깔고 띄운다. 기록이 없으면(지난 생 0, 저장 없음) 자동으로 펼쳐진다.
  안내문: ※ 15세 이상 이용자에게 권장합니다. / ※ TYPE-MOON 세계관에 대한 스포일러가 포함될 수 있습니다.

## 남은 것
- 로딩 화면(후보: 잔이 차오름 · 령주 · 소환진 · 열나흘 달력 · 별 + 그 겨울의 한 줄)
- 게임에 넣기: 배경 · 움직임, 로비 배치와 기존 기능 연결, 영어 · 일본어
- 키가 작은 휴대폰에서 ③의 달이 위쪽 버튼 근처로 올라감

`extra/`: 쓰지 않기로 한 그림(② 어두운 구름, 낮 하늘 네 장). 나중을 위해 보관.
